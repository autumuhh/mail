SECURITY BOUNDARY

调试台安全边界

  • 仅三步：密钥换令牌、邮箱信息查询、收件箱查询。
  • 仅内存：地址与访问令牌不会写入 localStorage、sessionStorage 或 URL。
  • 仅文本：响应统一写入 <pre>.textContent，邮件 HTML 不进入页面 DOM。
  • 不回显令牌：鉴权成功输出会主动移除 access_token。
